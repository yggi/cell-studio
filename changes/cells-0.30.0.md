### Changed
- **The language moves to v0.30.0** ([its changelog](https://github.com/yggi/cells/blob/main/CHANGELOG.md)):
  - **A value is what it says.** A wave below 0 patched into a share is held at 0 there, and a negative step in a sum is signed: a saved piece whose filter reads a bare wave (`lpf=200..3000 * &lfo` with `&lfo sin(12)`) now holds the filter shut for half of each cycle. Write the range the wave is read in, `sin(12, 0..1)` (`saw`, `tri` and `square` too), which the code view now suggests. `[&song + &breakdown]` with `&breakdown step=1m -.45` reads .05, not .775.
  - **The meter fragment is `bar`.** `from meter` finds no fragment, so a saved piece that takes it opens with an error until it is written as now: `&bar from meter &tempo` is `&bar from bar &tempo`, `from meter(swing=X) &tempo` is `&bar swing=X from bar &tempo`, `from meter(grouping=meter("3/4")) &tempo` is `from bar(meter="3/4") &tempo` (5/4, 7/8 and 10/8: `odd_meter`). The swung 4/4s are fragments of their own, `funk_meter`, `swing_meter` and `lofi_meter`. Ambient's bar is straight. A bar whose swing is set on its head draws one cell fewer (no `&bar_swing`); its meter's own cell is `&bar_meter`.
  - **The library has four new facets**, each a colour of its own on the map and the cards: `melodic` (the scales a lead walks), `fill`, `count` (a click, a stick count) and `ending` (a song's last bar and its ring), with the section kinds `solo`, `coro` and `mambo`, the song form `son_montuno` and the module `wander`. Two new examples: *A drum track in layers* (a count-in, a funk groove, a fill each phrase, the landing) and *A song that ends*.
  - **Recognition hears a progression's variations**: Extract can name a progression as a seed's moved a third or given a secondary dominant.
  - No example's notes move: *Patchbay*'s LFO holds 0 to 1 now (its events by at most .0022 of a value near 2657), and *Radio*'s bite drifts smoothly on `wander`.
- **The sun is Cell studio's own** (cells decision 086): `show=sun` draws as before. A `show=` word Cell studio doesn't draw is a warning, and the cell is drawn without it (it was an error); a piece can still not write a plugin of its own named like a show or the sun.

  A saved piece that takes `from meter`, or patches a bare wave into a share, needs its new spelling or sounds otherwise.
